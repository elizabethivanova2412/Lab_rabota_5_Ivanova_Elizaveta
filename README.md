# Лабораторная работа №5
## Нормализация реляционных баз данных

### 1. Исходное отношение
HDD (Производитель, Веб-сайт, Модель, Объём, Скорость вращения, Тип интерфейса, Серийный номер, Дата приобретения, Дата выхода из строя, Текстовые комментарии)

### 2. Функциональные зависимости
1. `Серийный номер → Модель, Дата приобретения, Дата выхода из строя, Текстовые комментарии`
2. `Модель → Производитель, Объём, Скорость вращения, Тип интерфейса`
3. `Производитель → Веб-сайт`

### 3. Нормализация и декомпозиция
- **1НФ:** все атрибуты атомарны.
- **2НФ:** первичный ключ — `Серийный номер`. Частичных зависимостей нет.
- **3НФ:** устранены транзитивные зависимости:
  - `Серийный номер → Модель → Производитель → Веб-сайт`
  - `Серийный номер → Модель → Объём, Скорость вращения, Тип интерфейса`

В результате декомпозиции выделены три отношения:
- **Производитель** (Производитель, Веб-сайт). Ключ: `Производитель`.
- **Модель** (Модель, Производитель, Объём, Скорость вращения, Тип интерфейса). Ключ: `Модель`.
- **Диск** (Серийный номер, Модель, Дата приобретения, Дата выхода из строя, Текстовые комментарии). Ключ: `Серийный номер`.

### 4. Проверка НФБК
Во всех отношениях детерминант ФЗ является первичным ключом:
- В «Производителе» детерминант `Производитель` (ключ).
- В «Модели» детерминант `Модель` (ключ).
- В «Диске» детерминант `Серийный номер` (ключ).
